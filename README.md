# Number Guessing Game

A simple number guessing game built with JavaScript. The program generates a random number between 1 and 100, and the player has to guess it.

## Live Demo
[Play the Number Guessing Game](https://num-guessing-game-js.netlify.app/)

## Features
- Random number generation
- User input through browser prompts
- Input validation
- Higher and lower hints
- Attempt counter

## What I Practiced
- While loops
- Conditional statements
- JavaScript Math methods
- Type conversion
- Input validation

## How to Play
1. Open the live demo.
2. Enter a number between 1 and 100.
3. Follow the hints to guess the correct number.
4. Try to get the answer in as few attempts as possible.
